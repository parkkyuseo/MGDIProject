Latin Square Condition Order Lookup

This sheet is for quick facilitator lookup by participant ID.

Base order: A = Macro Near, B = Macro Side, C = Micro Near, D = Micro Side. The numeric part of the participant ID determines the sequence.

Sequence patterns

  • Sequence 1: A -> D -> B -> C
  • Sequence 2: B -> A -> C -> D
  • Sequence 3: C -> B -> D -> A
  • Sequence 4: D -> C -> A -> B

Example: P15 uses participant number 15, so it uses Sequence 3: Micro Near -> Macro Side -> Micro Side -> Macro Near.
