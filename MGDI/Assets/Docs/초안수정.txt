\subsection{Objective Performance Measures}

The primary objective performance measures were task completion time and final manipulation error. These measures were recorded for each main trial. Task completion time measured the duration from the start of the trial to the participant's accepted submission. Participants submitted a trial when they judged that the active object matched the target as closely as possible. If a participant did not submit within the trial timeout, the trial was marked as timed out and the timeout state was recorded in the trial log.

Final manipulation error was computed according to the task type. For the translation task, translation error was computed as the Euclidean distance between the submitted tool and the placement target. In the implementation, this distance is evaluated using the renderer bounds centers of the active tool and target ghost when available, which avoids errors caused by object pivot offsets. The value is logged in meters internally and written to the study log in centimeters. For the rotation task, rotation error was computed as the angular difference between the submitted tool orientation and the target evaluation orientation, using Unity's quaternion angle calculation. This value was recorded in degrees. For the scaling task, scaling error was computed as the absolute difference between the submitted scale factor and the target scale factor. This factor error was multiplied by 100 and recorded as percentage-point error.

Together, task completion time and final manipulation error captured the efficiency and accuracy of each gesture condition. This was important because an interaction technique could allow participants to complete a task quickly while producing larger final error, or it could support more accurate manipulation at the cost of longer completion time. The study therefore considered both measures when evaluating objective performance.

The logging system also recorded secondary process measures that can support additional analysis. These included whether the trial timed out, whether the submitted state was treated as successful, the time to first enter the task tolerance, the number of eligible breaks after first entering tolerance, and the time spent recovering from leaving the tolerance region. For Micro conditions, the logger recorded phone-axis input effort as active-axis duration and axis integral. For Macro conditions, the logger recorded proxy-hand or wrist path length as a system-level movement-effort measure. The receiver also recorded raw phone path length, which represents physical phone translation and can differ from proxy-hand path length because gains, remapping, offsets, and smoothing affect the in-system control transform. Finally, the logger recorded Micro mode-switch count for tasks that used phone double-tap mode changes.
