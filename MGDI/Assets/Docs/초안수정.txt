\subsection{Objective Performance Measures}

The primary objective performance measures were task completion time and final manipulation error. These measures were recorded for each completed trial. Task completion time measured the duration from the start of the trial to the participant's submission. Participants submitted a trial when they judged that the active object matched the target as closely as possible. If a participant did not submit within the trial timeout, the trial was marked as timed out.

Final manipulation error was computed according to the task type. For the translation task, translation error was computed as the distance between the final submitted object position and the target position. This error was recorded in centimeters. For the rotation task, rotation error was computed as the angular difference between the final submitted object orientation and the target orientation. This error was recorded in degrees. For the scaling task, scaling error was computed as the difference between the final submitted object scale and the target scale. This error was recorded as a percentage error.

Together, task completion time and final manipulation error captured the efficiency and accuracy of each gesture condition. This was important because an interaction technique could allow participants to complete a task quickly while producing larger final error, or it could support more accurate manipulation at the cost of longer completion time. The study therefore considered both measures when evaluating performance.
